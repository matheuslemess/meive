## 📖 Sobre o Projeto

Este projeto é um **Web App Interativo** desenhado para ser uma experiência mobile-first "premium". Ele conta uma historinha através de slides animados, música de fundo e interações táteis, culminando na grande revelação: **A Meive foi promovida a Irmã Mais Velha!** 👶💖

A aplicação foi construída com foco em:

- **Fluidez**: Animações suaves e transições elegantes.
- **Estética**: Cores harmônicas (Rose & Amber), tipografia manuscrita e serifada.
- **Emoção**: Uma narrativa guiada que engaja os familiares e amigos.

## ✨ Funcionalidades

- 📱 **Mobile First**: Design 100% otimizado para celulares.
- 👆 **Navegação por Gesto**: Deslize para navegar entre os capítulos da história.
- 🎵 **Trilha Sonora**: Player de áudio integrado com _autoplay_ (após interação inicial).
- 🖼️ **Carrossel Infinito**: Galeria de fotos da família com efeito de chuva de amor.
- 🔒 **Slide Secreto**: Mecânica de "Toque e Segure" para revelar o segredo.
- 🎉 **Revelação Explosiva**: Efeito de confetes para o grande momento.
- 💬 **Integração com WhatsApp**: Botão direto para enviar parabéns aos pais.

## 🛠️ Tecnologias Utilizadas

- **[React](https://reactjs.org/)**: Biblioteca para construção da interface.
- **[Tailwind CSS](https://tailwindcss.com/)**: Estilização utilitária e animações.
- **[Vite](https://vitejs.dev/)**: Build tool ultrarrápida.
- **[Lucide React](https://lucide.dev/)**: Ícones leves e bonitos.
- **[Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)**: Efeitos de partículas.

## 🚀 Como Executar

Clone o projeto e instale as dependências para rodar localmente:

```bash
# 1. Clone o repositório
git clone https://github.com/seu-usuario/meive.git

# 2. Entre na pasta
cd meive

# 3. Instale as dependências
npm install

# 4. Rode o servidor de desenvolvimento
npm run dev
```

O projeto estará disponível em `http://localhost:5173`.

## 🎨 Estrutura de Slides

1.  **Capa**: "Olá! Tenho uma novidade..." (Gatilho de Áudio)
2.  **Intro**: "Aqui é a Meive..." (Apresentação)
3.  **Memórias**: Carrossel de fotos com a família.
4.  **Suspense**: Slide interativo "Segredo".
5.  **Revelação**: "Ganhei um Estagiário!" + Confetes.
6.  **Final**: Foto dos pais e botão de parabéns.
